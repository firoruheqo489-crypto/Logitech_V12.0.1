---

## 一、列名映射

| Excel 列名 | 系统字段 | 说明 |
|---|---|---|
| 里程碑 | milestoneLabel | 仅展示标签，不作为阶段识别主键 |
| 序号（兼容 工序序号） | wbsId | 支持 `1`、`1.1`、`6.2` 等层级编号 |
| 工序（兼容 工序名称） | name/stage | 通过 `STAGE_MAP` 映射 stage id + stageOrder |
| 项目工序预计完成时间 | baselineStart/baselineEnd | 当前按离散节点处理，start=end |
| 项目工序实际完成时间 | actualStart/actualEnd | 有值则标记完成 |
